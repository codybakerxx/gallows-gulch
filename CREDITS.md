## Tools used to make it

[FFmpeg](https://ffmpeg.org) (audio processing), [Pillow](https://python-pillow.org) and NumPy (texture baking and
analysis), [Playwright](https://playwright.dev) with Chromium (the test harness and screenshots), and the Whisper
speech-recognition model run with [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) (checking each recorded line).
